# Evidence rules

Create screenshots or saved output only from real sessions. Do not reconstruct missing evidence after the fact.

For every important claim, record:

- date and session ID;
- Codex task identity or screenshot filename;
- exact prompt/input;
- visible model response;
- memory tool name and returned status/identifier;
- namespace;
- whether recall later confirmed the event;
- any ambiguity or failure.

Suggested screenshot names:

```text
s1-01-health-login.png
s1-02-first-mistake-write.png
s1-03-original-update-language.png
s2-01-cold-weakness-briefing.png
s2-02-progress-event.png
s3-01-mastery-proof.png
s3-02-duplicate-blocked.png
```

Never include wallet secrets, delegate private keys, credentials files, seed phrases, passwords, or authentication codes.
